# Qiuqiu Obsidian Home

一个为个人第二大脑设计的 Obsidian 首页插件。

> 首页不是展示全部信息，而是降低“下一步行动”的摩擦。

## 产品定位

Qiuqiu Home 是位于 Obsidian Vault 与日常行动之间的一层个人操作台。

首页组织成四个层级：总览、行动、知识、生活。

本项目借鉴的是个人首页应承担的功能模型，而不是复制任何特定项目的源码、文案、视觉或资源；信息架构、命名、视觉语言和代码均重新设计。

## 当前能力

- 启动时自动打开独立 Home View
- 日期 / 时间与分区导航
- 本地 Markdown 即时搜索
- 精确匹配直接打开，无匹配时创建笔记
- 自动创建安全的 Markdown 文件名
- 自动定位、创建、打开今日日记
- 今日重点写入 daily note frontmatter
- 一句话写入 Inbox 或今日日记
- 扫描最近 N 天任务并直接回写原 Markdown
- 最近修改笔记
- 最近 7 天知识活跃度与标签
- 周 / 月知识活跃度入口
- 日记连续记录天数
- 人生领域任务完成概览
- Vault 基础状态统计
- 快捷入口可配置
- 首页卡片可隐藏
- 首页卡片可拖拽排序并持久化
- 人生领域目录与颜色可配置
- 响应式视觉系统

## 本地开发

运行 npm install 后执行 npm run build。

构建后将 main.js、manifest.json、styles.css 放入 .obsidian/plugins/qiuqiu-obsidian-home/，然后在 Obsidian 设置中启用。

## 设计原则

### Vault 是唯一真相源

首页不建立第二套笔记数据库。

### 首页只做读 + 少量写

复杂编辑仍然回到原始 Markdown。

### 信息服务于行动

任何模块都应该回答：我看到它之后，下一步能做什么？

### 不为了像产品而产品化

首页越漂亮越容易变成仪表盘玩具。这个项目最终应该成为每天真正会打开的入口。
